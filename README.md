## Atividade Avaliativa - Classificação Multiclasse com Rede Neural

- Executar primeir o arquivo `one_hot.py` para classificar o dataset e gerar o one hot para a rede neural.
- Executar então o arquivo `rede_neural.py` para a rede neural aprender com os dados do dataset classificado.
- A mesma rede irá aplicar o aprendizado aos 10 alunos adicionados em `alunos_teste.py` gerando os resultados e porcentagens de previsão.
